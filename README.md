# 📦 Product Inventory Manager (HTML, CSS & TypeScript)

A clean, responsive, browser-based **Product Inventory Manager** built with vanilla **HTML5**, modern **CSS3**, and **TypeScript** (transpiled to standard JavaScript).

This project is designed as an **MCA / Computer Science student assignment** demonstrating fundamental TypeScript programming, DOM manipulation, clean design, and frontend workflows without third-party frameworks or libraries.

---

## 🚀 Live Demo & Features

- **Add Product Form**: Input product name, unit price, and quantity with input validation.
- **Dynamic Table Display**: Auto-generated sequential IDs, formatted currency, item totals, and responsive table layout.
- **Item Removal**: One-click product deletion with automatic table and summary recalculations.
- **Real-Time Summary Statistics**: Dynamic counters for **Total Products** and **Total Inventory Value**.
- **Input Validation**: Client-side checks for non-empty names, positive prices, and positive integer quantities with user-friendly error banners.
- **Pure Web Technologies**: Zero external dependencies (No React, Angular, Bootstrap, or Tailwind). Works right in any modern web browser.

## 🧠 Key TypeScript Concepts Demonstrated

### 1. Basic Data Types
Explicitly typed primitive values:
- `string`: `name: string`, `message: string`
- `number`: `id: number`, `price: number`, `quantity: number`, `total: number`
- `boolean`: `isValid: boolean`

### 2. Interfaces
A custom contract defining the shape of a product object:
```typescript
interface Product {
    id: number;
    name: string;
    price: number;
    quantity: number;
}
```

### 3. Strongly Typed Arrays
Managing in-memory state with an array of objects conforming to the interface:
```typescript
let inventory: Product[] = [];
```

### 4. Typed Functions & Return Types
Functions with typed parameters and explicit return signatures:
- `addProduct(): void`
- `displayProducts(): void`
- `deleteProduct(productId: number): void`
- `calculateTotalValue(): number`
- `updateSummary(): void`
- `validateInput(name: string, price: number, quantity: number): boolean`

### 5. Variable & Function Scope
- **Global / Module Scope**: `inventory`, `nextProductId`, and DOM element references accessible throughout the script.
- **Local / Block Scope**: Variables inside functions (e.g., `isValid`, `row`, `itemTotal`, `total`) only accessible within their respective function or loop block.

### 6. DOM Manipulation & Type Assertions
Using TypeScript type assertions to safely interact with DOM elements:
```typescript
const productNameInput = document.getElementById("product-name") as HTMLInputElement;
const addProductBtn = document.getElementById("add-product-btn") as HTMLButtonElement;
```

## 🛠️ Step-by-Step Setup & Usage Guide

### 1. Prerequisites
- **Node.js** (includes npm) installed on your system.
- Check via terminal:
  ```bash
  node -v
  npm -v
  ```

---

### 2. How to Compile TypeScript to JavaScript

1. Open your terminal in the project directory:
   ```bash
   cd "Product Inventory Manager"
   ```

2. Compile `script.ts` using the TypeScript compiler:
   ```bash
   # If TypeScript is installed globally:
   tsc

   # Or using npx (no global install needed):
   npx tsc
   ```

3. **Auto-compile on file changes (Watch Mode)**:
   ```bash
   npx tsc --watch
   ```

---

### 3. How to Run the Project Locally

#### Option A: Direct Browser Opening (Easiest)
- Double-click `index.html` in your file explorer, or right-click and choose **Open with > Chrome / Edge / Firefox**.

#### Option B: VS Code Live Server Extension
1. Install the **Live Server** extension in VS Code.
2. Right-click on `index.html` and select **"Open with Live Server"**.

#### Option C: Simple Python HTTP Server
```bash
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.

## 🎓 Viva / Practical Exam Preparation Guide

### Sample Q&A for MCA Practical Exam:

1. **Q: Why do we use TypeScript instead of plain JavaScript?**
   - **A:** TypeScript adds static typing, interfaces, and compile-time error detection to JavaScript. This prevents common runtime bugs (such as passing a string where a number is expected) and improves code maintainability.

2. **Q: Can a web browser execute `.ts` files directly?**
   - **A:** No. Browsers only execute JavaScript (`.js`). The TypeScript compiler (`tsc`) transpiles TypeScript code into standard JavaScript that any browser can understand.

3. **Q: What is an Interface in TypeScript?**
   - **A:** An `interface` is a syntactical contract in TypeScript that defines the shape of an object (properties and their data types) without implementing any behavior. In our project, `interface Product` enforces that every product has an `id`, `name`, `price`, and `quantity`.

4. **Q: What is the difference between Global and Local scope in this project?**
   - **A:** The `inventory` array and `nextProductId` have global/module scope so all functions can read and modify them. Variables like `isValid`, `row`, and `itemTotal` inside functions have local/block scope, meaning they are created when the function executes and discarded when it finishes.

5. **Q: What is Type Assertion (`as HTMLInputElement`)?**
   - **A:** `document.getElementById()` returns a generic `HTMLElement | null`. Using `as HTMLInputElement` tells TypeScript that the element is specifically an `<input>` element, granting safe access to properties like `.value`.
